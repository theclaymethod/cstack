# From captured findings to cases

Use a local Expert Mode/Distill Me dataset directly within its established private project. For a supplied export, inspect its manifest and review receipt against the current content hashes. Preserve missing or stale privacy and intent review as limitations; exporting a bundle does not settle either review automatically. Do not transmit or publish it merely because it can be opened locally.

Resolve the current state of each example from its history. A later correction, narrower criterion, or retraction amends the original judgment rather than adding another independent case. Two distinct assertions in one output can remain separate cases with a shared source family. Repeated transcript excerpts and reviewer extractions are not independent observations.

Map fields by meaning:

| Captured evidence | Eval use |
| --- | --- |
| Recoverable original input and selected context | Replay input; name unavailable artifacts explicitly. |
| Original reviewed output/version | Stored output for judge calibration, or evidence of an observed failure. A new product run produces a separate output. |
| Explicit current expert judgment | Potential calibration gold for that scoped assertion; preserve uncertainty and dissent. |
| Expert-authored or endorsed correction | Approved reference content with its conditions and alternatives. Null remains null. |
| Rubric definition and version | An applicable check only when its question and passing answer are settled. |
| Sources and amendments | Private provenance and family grouping; omit label-revealing material from blind payloads. |
| Preference or tentative concern | Its own annotation type; score only if an explicit task requirement establishes a criterion. |
| Replay blockers | Incomplete queue and exclusion counts; never silently coerce them into failures or successes. |

Capture readiness and post-redaction readiness are different. Confirm that masked names, IDs, dates, units, graph relationships, and source references still support the criterion. A source-naming error may be rejectable without knowing the correct numerical estimate; that does not establish numerical truth.

Separate two uses of a negative finding:

1. **Judge calibration:** grade the preserved output against its supported expert label without revealing that label to the judge.
2. **Product evaluation:** replay the original task against the current system and grade the newly produced result. The old output's FAIL label does not predetermine the new result.

If an export has only paths, a summary, or an isolated correction without recoverable original evidence, preserve the finding as incomplete. Ask one focused clarification only when it materially changes the example. Do not fill gaps with invented outputs, thresholds, or expert endorsements.
