# Intent criteria fixed before source review

1. Native support grader determines task correctness: preserve prior state, authorization, account/duplicate scope and declared schema; accept any valid unique ID and allowed action.
2. Adapter runs changed artifacts with deterministic bounded controls. It is neither a second grader nor a security sandbox.
3. Freeze task, evaluator, original quality baseline, regressions and necessary information. Keep failed executions and selected denominators visible.
4. Preserve resource accounting across public workflows, reserve final resources and freeze final configurations; distinguish operator corruption from candidate access.
5. Ablation contribution evidence differs from combined deletion selection; claims stop at tested configurations. Model migration needs original and new existing-design comparisons and shared design for interactions.
6. Offline synthetic results do not imply production quality, efficiency, hidden-label integrity or host containment.
7. Repairs must retain valid original alternatives and include teaching/reference guidance appropriate to confirmed failure, without silently changing grader semantics.
