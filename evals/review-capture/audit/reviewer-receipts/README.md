# Independent review execution receipts

`original-native-command.txt` and `original-native-observed-tool-output.txt` transcribe the exact executed shell/Python command and its returned stdout from the retained tool interaction. The outer command exited 0. Its two native subprocesses each returned 0; their parsed outputs matched the frozen native traces and showed ticket deltas 0 and 1.

The two native subprocesses' **raw stdout and stderr were not persisted**. Only their parsed-output equality, exit and state-delta summaries survive. `original-native-invocation-receipts.json` records that limitation and the frozen program/trace hashes. The `*-reconstructed-stdin.json` files reproduce the exact deterministic stdin expression from the unchanged trace; they are reconstructed inputs rather than contemporaneously saved stdin receipts. No native candidate was rerun to create these records. The historical trace's stdout must not be represented as the stdout of the independent invocations.

The four original repaired-checker reruns returned complete stdout/stderr through the tool interaction but were not initially saved as files. Four **additional read-only checker runs** were made for durable raw receipts using `collect_checker_receipts.py`. Each `additional-checker-*` folder contains exact raw stdout/stderr bytes, command/cwd/exit metadata, and before/after SHA-256 inventories of every archive file. All four archive inventories are unchanged. The valid baseline exits 0; the three corrupted archives exit 1 with the expected specific mismatch. These extra runs execute no native candidate and perform no inference or provider/network calls.
