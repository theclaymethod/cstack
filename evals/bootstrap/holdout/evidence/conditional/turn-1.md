# Kanban welcome demo

The proposed promise is that a person who opens the Kanban welcome screen can watch the demo in either supported editor described below.

| ID | Starting situation | Proposed observable outcome |
| --- | --- | --- |
| KW-01 | A person opens the welcome screen in VS Code and starts the updated demo as before. | The demo plays in the welcome screen, with visible frames that advance. |
| KW-02 | A person opens the same screen in JetBrains and starts the updated demo. | The demo plays in the welcome screen, with visible frames that advance. |

Both entries await review. The open boundary is whether JetBrains must play the demo in the welcome screen or whether another viewing path is acceptable.
