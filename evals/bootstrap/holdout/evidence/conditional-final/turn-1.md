# Kanban welcome demo

The proposed promise is that someone opening the Kanban welcome screen can watch the demo in either editor.

| ID | Starting situation | Expected user-visible outcome |
| --- | --- | --- |
| KAN-001 | A VS Code user opens the welcome screen with the updated video. | The demo still plays, as it did before the change. |
| KAN-002 | A JetBrains user opens the same screen where the previous player appeared blank. | The user can watch the updated demo. What they should see or do before playback starts is open. |

Both entries await confirmation. There are no existing playback checks in this directory.
