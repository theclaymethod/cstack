# Kanban welcome demo

The proposed promise is that someone opening the Kanban welcome screen can watch the demo in either editor.

| ID | Starting situation | Expected user-visible outcome |
| --- | --- | --- |
| KAN-001 | A VS Code user opens the welcome screen with the updated video. | The demo still plays, as it did before the change. |
| KAN-002 | A JetBrains user opens the same screen where the previous player appeared blank. | During playback, the user sees the Kanban demo advance beyond its opening frame. |

The index is a draft. For KAN-002, whether playback starts automatically or waits for Play remains undecided. There are no existing playback checks in this directory.
