# Kanban welcome demo

**Proposed promise.** A person opening the Kanban welcome view can watch the demo in VS Code and JetBrains.

| ID | Starting situation | Proposed observable outcome |
| --- | --- | --- |
| KAN-001 | A VS Code user opens the welcome view and starts the updated demo as before. | The video plays in the welcome view. The user sees the board actions unfold. |
| KAN-002 | A JetBrains user opens the same view and tries to watch the updated demo. | The user can watch the board actions unfold. Whether playback must happen inside the welcome view is open. |

**Open boundary.** If the embedded JetBrains player cannot play the demo, would a link that plays the same demo in a browser satisfy KAN-002?

Both entries await developer review. This directory contains no implementation or existing playback checks to inspect.
