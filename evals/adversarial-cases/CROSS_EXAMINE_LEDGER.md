## AC-01: closed ticket key set rejected a permitted outcome

**Confirmed native false rejection.** The source spec/rubric requires creation to append one unique-ID, selected-account, open VPN ticket while preserving all original state. It explicitly closes the outer output keys, but does not close ticket keys. `valid_ticket` imposed an exact four-key record. A candidate satisfying every written creation requirement plus `created_at` returned ERROR; removing only that field returned PASS. Rich-state and reduced empty-state contrasts isolate the same mechanism.

Raw case, candidate-authored minimal pair, native manifests/stdout/traces/summaries and commands: [extra-field reduction](evidence/cross-examine/semantic-cases/extra-field-reduction/commands.json). [Independent observation review](evidence/cross-examine/native-ticket-observation-review.md) accepted the narrow discrepancy before repair. Root separately reproduced the same PASS/ERROR pair from clean frozen native source. This is not a flaw in the known intentionally defective exercise proxy or proof that the shared skill generally fails.

**Repair:** require and type-check the four mandatory ticket fields while accepting additional JSON metadata. Outer output shape, action/account, actual membership, uniqueness and exact prior-state preservation remain checked. The added native regression executes metadata-bearing creation, feeds that state into another request, and rejects changed original metadata. The source spec/rubric and original cases are unchanged; campaigns must use a fresh baseline after evaluator changes.

**Replay:** `python3 evals/adversarial-cases/cross_examine.py --out eval-runs/adversarial-audit`. Frozen native source rejects the five-field candidate; repaired source accepts both four/five-field candidates. The new native test fails on the old evaluator and passes on the repair. Existing negative and valid controls are retained. The [injection reference](../../skills/adversarial-cases/references/injection.md) teaches schema-alternative and metadata-preservation construction.

## AC-02: replay trusted incomplete or contradictory recorded evidence

**Confirmed fixed-replay validation gap; operator calibration.** The replay iterated whatever observation/command arrays were supplied and accepted matching source dictionaries without checking membership or actual files. It also read parsed outputs/verdicts without the existing native retained-run checker. On copied evidence, omitted treatment observations passed (64 assertions), an empty lifecycle list passed (46), a deleted native-command entry plus standalone receipt passed (70), contradictory raw stdout/parsed output passed (71), and two empty source inventories passed (71). The native checker correctly rejected the stdout conflict. The complete unmodified baseline passed (71).

Raw changes/results: [trust receipts](evidence/cross-examine/receipts.json), [coverage receipts](evidence/cross-examine/coverage-receipts.json), [independent trust review](evidence/cross-examine/operator-validator-observation-review.md), [independent coverage review](evidence/cross-examine/operator-coverage-observation-review.md). Native measurement artifacts remained present in omission probes; these experiments do not establish that a case never ran. Source inventories were cleared without editing protected source, so they establish missing evidence, not undetected actual source mutation. They require operator writes to evidence; no candidate-access exploit or failure of the normal trusted constructor is claimed.

**Repair:** require the fixed contract's four unique lifecycle observations and 22 unique commands with matching standalone receipts; require complete core/installed-skill source membership and actual current hashes; revalidate all seven native runs with native `checked_run` before reading their outcomes. The control path now has 103 assertions. This fixed inventory applies to this exercise, not to every shared-skill handoff. Consistency checks provide no guarantee against an operator that can rewrite protected host files.

**Replay:** the portable audit creates fresh real native artifacts, then applies all five exact mutations to separate copies. The frozen validator accepts them; the repaired validator rejects all five and accepts the unmodified control. Mutations execute no additional candidates or faults. The [case contract](../../skills/adversarial-cases/references/case-contract.md) now teaches required coverage/source membership and native retained-output verification.
