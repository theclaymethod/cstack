# Copied skill sources

The local skill copies under `.agents/skills` come from [C Stack](https://github.com/theclaymethod/cstack), authored for Clayton Kim under the MIT license. The lock records their installed version and complete content hashes. This test project's support agent, evaluator, scripts, fixtures, and exercises are original playground code under [LICENSE](LICENSE).

C Stack's Expert Mode and Distill Me adapt working-mode and retrospective review patterns from Lauren Tan's [Pstack](https://github.com/cursor/plugins/tree/main/pstack), especially Poteto Mode, Automate Me, and Reflect. Its [MIT license](licenses/pstack-MIT.txt) is retained.

Create Eval and Run Eval adapt earlier Clayton Kim workflows. Cross-Examine originated in the standalone Cross-Examine repository. C Stack's [source record](https://github.com/theclaymethod/cstack/blob/main/SOURCES.md) describes the origins and inspected revisions.

External optimizer frameworks, AI Evals Course skills, and OpenAI Privacy Filter are referenced by the installed skills but are not installed by this test repo. No model weights, provider SDK, hosted service, or external optimizer code is bundled here.
