Cheat sheet

Turn expert judgment into evals, improve an agent against them, and remove complexity that no longer helps.

Install
npx skills add theclaymethod/cstack \
  --skill expert-mode distill-me bootstrap create-eval run-eval cross-examine \
  hill-climb adversarial-cases calibrate-judge ablation bitter-lesson help tutor \
  -a codex -a claude-code -a cursor --copy
Typical order
1 · Capture

expert-mode while you work, or distill-me after the session. bootstrap when you know the behavior and have no useful traces yet.

2 · Author

create-eval turns reviewed evidence into cases and graders. calibrate-judge when a semantic judge must agree with authoritative labels.

3 · Measure

run-eval executes and keeps the receipt. cross-examine challenges the score. adversarial-cases builds the hard inputs and controls.

4 · Change

hill-climb improves against a fixed eval. ablation removes parts. bitter-lesson revisits old steering after a model change. Then measure again.

Skill Reach for it when
expert-modeYou are about to work and can say what is wrong, acceptable, or still uncertain.
distill-meThis session already contains judgments that are not saved as records.
bootstrapYou can describe the behavior and need the first reviewed scenarios before traces exist.
create-evalReviewed judgments or approved scenarios should become cases and graders.
calibrate-judgeA judge will score meaning, and you have authoritative labels to fit it against.
run-evalCases exist and you need a fresh execution receipt, not a remembered score.
cross-examineA pass or fail may be crediting the wrong outcome or rejecting a legitimate one.
adversarial-casesYou need a small constructed challenge, fault, or control. Approval stays with the parent skill.
hill-climbA fixed evaluator shows failures and you may edit only the authorized target.
ablationThe target meets the quality bar and you want to delete instructions, tools, or steps.
bitter-lessonA model change may make inherited prompt or scaffolding unnecessary. Removal still has to clear the old bar.
helpYou are unsure which skill fits. It reads the files you already have and names one next step.
tutorYou want to practice the pack. It teaches playground exercises 01–13, one question at a time.

What a result is

Untuned is the original target. Synthetic and adversarial cases are constructed. True labeled data is a human judgment on a real example, only inside the scope that was reviewed.
